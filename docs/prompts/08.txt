Задача: Исправить ошибку создания временной папки для ffmpeg воркера.

Текущая проблема: Воркер падает с ошибкой: `create temp dir: stat tmp/storage/tmp: no such file or directory`. Это происходит потому, что код видеопроцессора пытается проверить или создать временную директорию по жестко захардкоженному пути `tmp/storage/tmp`, вместо того чтобы использовать базовый путь хранилища из конфигурации (`cfg.StorageRoot`) и функцию `os.MkdirAll`, которая создает родительские папки автоматически.

Твоя задача:
1. Найди метод конвертации внутри `internal/infrastructure/worker/video_processor.go`.
2. Исправь логику инициализации временных папок. Путь должен собираться динамически (например, через `filepath.Join(storageRoot, "tmp", assetID)`).
3. Для создания папок используй строго `os.MkdirAll(dir, 0755)`, чтобы избежать ошибок отсутствия родительских папок на диске.

Выдай только исправленный кусок кода функции конвертации видео.
