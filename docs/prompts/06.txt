Мы переходим к Спринту 4: Реализация фонового асинхронного воркера для обработки видео через ffmpeg (Задачи T4.1 - T4.4).

Нам необходимо реализовать:
1. Метод в репозитории `internal/infrastructure/persistence/postgres/media_repository.go` для получения следующей задачи на обработку. Запрос должен использовать `SELECT ... FOR UPDATE SKIP LOCKED`, чтобы несколько воркеров не хватали одну таску. Статус задачи должен атомарно меняться на 'processing'.
2. `internal/infrastructure/worker/video_processor.go` — имплементация интерфейса `VideoProcessor`. Код должен через `exec.CommandContext` вызывать системный `ffmpeg` для конвертации исходного MP4 в HLS (генерация мастер-плейлиста .m3u8 и сегментов .ts). Результат должен складываться во временную папку, а затем атомарно перемещаться в финальную директорию хранилища (`StorageRoot/hls/{asset_id}/`).
3. `internal/usecase/media/worker_usecase.go` — логика воркера. В бесконечном цикле (с тикером, например, каждые 3-5 секунд) запрашивает задачу из репозитория, запускает обработку через `VideoProcessor`, и по итогу обновляет статус в БД на 'success' или 'failed'.
4. `cmd/worker/main.go` — точка входа для бинарника воркера. Он должен инициализировать конфиг, логгер, пул подключений к БД и запускать фоновый процесс обработки.

Пиши чистый идиоматичный Go-код строго под наш модуль github.com/aimv/media-gallery. Выдай готовый код файлов в Markdown-блоках.
