Этап /opsx:archive для задачи T1.1 успешно завершен, проект компилируется.

Переходим к этапу /opsx:propose -> /opsx:apply для задач T2.1 и T2.2 (Инфраструктура СУБД, конфигурация и логгер).

Сгенерируй код для следующих файлов:

1. `docker-compose.yml` — должен поднимать PostgreSQL (образ postgres:16-alpine) на стандартном порту, настраивать volume для сохранения данных базы и прокидывать переменные окружения.
2. `.env` и `.env.example` — конфигурационные файлы с доступами к этой базе данных, портами и папками для медиафайлов.
3. `internal/infrastructure/config/config.go` — чистая структура Config на стандартной библиотеке `os`, которая считывает эти переменные окружения и валидирует их (если важная переменная пустая — возвращает понятную ошибку).
4. `internal/pkg/logger/logger.go` — простая обёртка над стандартным логгером Go `log/slog` (Structured Logging), чтобы логи выводились в красивом JSON-формате с указанием уровня (INFO, ERROR).
5. `internal/infrastructure/persistence/postgres/migrations/000001_init.up.sql` — чистый SQL-код создания таблиц `media_assets`, `processing_jobs` и `content_blocks` со всеми индексами и связями, которые мы утвердили в design.md.
