# OpenSpec Change Proposal: T1.6 Setup GitHub Actions CI Workflow

## Objective
Настройка пайплайна непрерывной интеграции (CI) на базе GitHub Actions для автоматического контроля качества кода, проверки статического анализа и прогона тестов при каждом событии push и pull request.

## Scope
- Создание декларативного файла конфигурации `.github/workflows/ci.yml`.
- Настройка шагов: установка Go 1.26, кэширование зависимостей, запуск линтера и тестов.
