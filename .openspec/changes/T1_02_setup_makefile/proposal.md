# OpenSpec Change Proposal: T1.2 Setup Makefile

## Objective
Создание автоматизированного конфигурационного файла `Makefile` для унификации консольных команд компиляции, тестирования, линтинга и запуска распределенных компонентов медиагалереи.

## Scope
- Определение декларативных целей: `build` (компиляция cmd/api и cmd/worker), `test`, `lint`.
- Настройка команд локального запуска `run-api` и `run-worker`.
