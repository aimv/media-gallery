# OpenSpec Change Proposal: T4.1 PostgreSQL Queue ClaimNext Implementation

## Objective
Реализация распределенного механизма конкурентной очереди задач на базе СУБД PostgreSQL с использованием атомарных транзакционных блокировок `SELECT ... FOR UPDATE SKIP LOCKED` для обеспечения параллельной утилизации ресурсов несколькими воркерами обработки видео.

## Scope
- Определение доменной сущности `ProcessingJob` и интерфейса `QueueRepository` в слое ядра.
- Реализация адаптера репозитория очереди задач в слое инфраструктуры СУБД.
