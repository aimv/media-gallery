# OpenSpec Change Proposal: Backlog Decomposition Across 6 Sprints

## Objective
Тотальная декомпозиция глобальных требований монолитной архитектуры MVP медиагалереи на атомарный, сквозной бэклог микро-задач (более 20 шагов) для минимизации размера диффов в Git-коммитах (до 200–300 строк на шаг) и обеспечения контролируемого Spec-Driven процесса разработки.

## Scope & Sprint Architecture
Декомпозиция выполняется строго по 6 технологическим этапам, заявленным бизнесом:
1. **Спринт 1 (Каркас и QA)**: Инициализация модуля, Makefile, конфигурация `golangci-lint` и пайплайна GitHub Actions CI/CD (авто-прогон тестов и линтеров), внедрение пакета `slog` и доменных ошибок.
2. **Спринт 2 (Persistence)**: Поднятие изолированной PostgreSQL 16 с healthcheck в Docker Compose, парсинг конфигурации `.env` через `godotenv`, интеграция встроенного инструмента накатывания миграций `golang-migrate` (0001_init.up.sql).
3. **Спринт 3 (Загрузка)**: Domain-модели, потоковое сохранение в Local FileStorage с валидацией Magic Bytes по реальному содержимому (`http.DetectContentType`) и strict JSON REST API (`POST /api/v1/media/upload`), покрытие Unit- и интеграционными тестами.
4. **Спринт 4 (Воркер)**: Фоновый конкурентный Worker Pool на горутинах, механизм распределенного захвата задач через атомарный `SELECT ... FOR UPDATE SKIP LOCKED`, логика продления аренды (Heartbeat/Lease) и вызов `ffmpeg` через `exec.CommandContext`.
5. **Спринт 5 (CMS-модуль)**: CRUD-репозиторий блоков с транзакционной привязкой медиафайлов через нормализованную таблицу-линковку `block_media_links` по колонке `asset_id`, сериализация в JSONB-data, REST-хендлеры на базе Path Values Go 1.22+.
6. **Спринт 6 (Оркестрация)**: Финальные multi-stage Dockerfiles (`golang:1.26-alpine`), сквозной docker-compose.yml для 3 сервисов, отладка healthcheck `/healthz` и экспорт готовой демонстрационной коллекции Postman v2.1.

## Non-Goals
- Написание или изменение исходного кода Go на текущем шаге.
- Изменение утвержденных реляционных связей и интерфейсов портов из `docs/2_DESIGN.md`.
