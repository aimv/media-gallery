# OpenSpec Change Proposal: T4.7 Atomic HLS Stream Directory Relocation Mechanics

## Objective
Внедрение механизмов обеспечения транзакционной целостности на уровне файловой системы при публикации HLS-потоков. Видеосегменты и мастер-плейлисты генерируются утилитой `ffmpeg` в изолированной временной папке (`tmp/hls/`), исключая преждевременный доступ клиентов API к недописанному контенту, и атомарно перемещаются в публичную директорию хранилища только после успешного завершения кодирования.

## Scope
- Расширение интерфейса `FileStorage` методом `MoveDir`.
- Реализация атомарного системного переноса директорий в компоненте `LocalStorage`.
- Модификация `ProcessVideoUseCase` в части разграничения временных и постоянных путей компиляции HLS.
- Написание модульного теста переноса папок в `local_test.go`.
