# OpenSpec Change Proposal: T4.4 Video Validation Verification via ffprobe Mock Testing

## Objective
Обеспечение полной тестовой верификации компонента `FFmpegProcessor` в части извлечения технических метаданных через `ffprobe`. Разработка тестов гарантирует стабильный парсинг JSON-вывода, корректное преобразование секунд в миллисекунды и маппинг системных сбоев на доменные ошибки уровня `apperror.ErrInvalidInput`.

## Scope
- Расширение тестового пакета `internal/infrastructure/video/ffmpeg_processor_test.go`.
- Создание сценариев тестирования успешного разбора JSON-потока метаданных.
- Создание сценариев тестирования валидации некорректных медиаконтейнеров с контролем возвращаемых типов ошибок.
